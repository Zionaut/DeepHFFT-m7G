# 🧬 DeepHFFT-m7G User Manual

## I. Installation and Usage Guide

### 1. Installation Steps

Run the following commands in your terminal:

```bash
# Clone the repository
git clone https://github.com/Zionaut/DeepHFFT-m7G.git
cd DeepHFFT-m7G

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

------

### 2. Usage Instructions

Execute the following commands to run each stage of data processing and model training:

```bash
python rna3d.py
python cdv.py
python cgd.py -k 25
python cf.py
python train2.py -k 25 -e 100
```

#### Parameter Description

| Parameter | Description               | Default |
| --------- | ------------------------- | ------- |
| `-k`      | Sequence label            | 25      |
| `-e`      | Number of training epochs | 100     |

------

### 3. Input and Output Examples

#### ▶ Example Command

```bash
python train2hm.py -k 25 -e 100
```

#### Input File Structure

The program automatically loads training and testing data from the directory `../experiments/501bp/`:

| File Path                                                  | Description                                |
| ---------------------------------------------------------- | ------------------------------------------ |
| `../experiments/501bp/one_hot/train_one_hot.npy`           | One-hot encoded training sequence features |
| `../experiments/501bp/chem/train_chem.npy`                 | Chemical feature matrix                    |
| `../experiments/501bp/eiip/train_eiip.npy`                 | EIIP numerical features                    |
| `../experiments/501bp/enac/train_enac.npy`                 | ENAC encoding features                     |
| `../experiments/501bp/dna2vec/4mer_rna7train_features.npy` | RNA2Vec 4-mer embedding features           |
| `../experiments/501bp/dna2vec/5mer_rna7train_features.npy` | RNA2Vec 5-mer embedding features           |
| `../experiments/501bp/dna2vec/6mer_rna7train_features.npy` | RNA2Vec 6-mer embedding features           |

> ⚠️ **Note:** These files are automatically generated by the preprocessing scripts
> `rna3d.py`, `cdv.py`, `cgd.py`, and `cf.py`.
